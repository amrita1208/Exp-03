# Exp - 3 RAILWAY MANAGEMENT SYSTEM

# AIM:

To develop a Railway Management System by identifying the system requirements and representing the system using appropriate UML diagrams.

# SRS (Procedure):
1.Identify the requirements of the Railway Management System.

2.Identify the main users/actors such as Passenger, Railway Staff and Administrator.

3.Identify the major functions such as:

 .User registration and login
 
 .Train search
 
 .Ticket booking
 
 .Ticket cancellation
 
 .Checking train availability
 
 .Payment
 
 .Viewing booking details
 
 .Managing train and passenger details
 
4.Prepare the Use Case Diagram to represent the interactions between users and the system.

5.Prepare the Class Diagram to represent the classes and their relationships.

6.Prepare the Sequence Diagram to show the sequence of operations during ticket booking.

7.Prepare the Activity Diagram to represent the workflow of the railway booking process.

8.Prepare the Component Diagram to represent the software components of the system.

9.Prepare the Deployment Diagram to represent the physical deployment of the railway management system.

10.Verify that all requirements and system interactions are properly represented in the diagrams.
